# 🐙 Charlotte's Claude Code Plugins

**Claude Code plugins and slash commands that scale AI automation for overwhelmed founders.**

## Philosophy

Every plugin solves a real problem I had first. If it doesn't save me time, it doesn't exist.

## Available Plugins

### Session Documentation
- **`/doc-session`** - Document work sessions with Zapier integration to Google Sheets
- Auto-generates Obsidian-formatted markdown with 16 tracked fields
- Logs to activity dashboard for weekly reviews

### LinkedIn Engagement
- **`/engage-linkedin`** - Strategic commenting framework with ADHD accommodations
- 3-question filter (Why here? Can I add value? Will I regret this?)
- Emoji system for fast visual scanning

### Email Management
- **`/triage-emails`** - Gmail automation with archive-by-default approach
- Reduced inbox from 201 to 1 email (99.5% reduction)
- Smart categorization and bulk actions

### AI Learning
- **`/level-up`** - Track skill gaps and generate learning materials
- Creates NotebookLM podcast sources from gap analysis
- Weekly progress dashboard integration

### Research & Truth-Seeking
- **`/seek-truth`** - 4 modes for evening research (Video, Deep Dive, Connect Dots, Brain Dump)
- Saves to Truth Vault with structured templates

### ADHD Support
- **`/adhd-dashboard`** - Visual overview of current work, priorities, and next actions
- Emoji-based quick scanning
- Integrates todo lists, session docs, and project status
